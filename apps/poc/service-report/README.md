# 월간 서비스 리포트 — 양식과 데이터

발행은 `템플릿 + 데이터 → PDF`다. 템플릿은 한 번 만들고 매달 재사용하며,
바뀌는 것은 데이터 파일 하나뿐이다.

| 파일 | 무엇인가 |
|---|---|
| `template.json` | 양식. 담당자가 편집기로 만드는 것이 이것까지다 |
| `data.july.json` | 2026년 07월 발행 데이터 (처리내역 23건) |
| `data.august.json` | 데이터만 바꾼 예 (처리내역 7건) |
| `publish.mjs` | 양식과 데이터로 PDF를 만드는 스크립트 |

## 발행

```bash
node apps/poc/service-report/publish.mjs <데이터파일> <나올파일>
```

같은 양식에 7월 데이터를 넣으면 10쪽(`01 / 10`), 8월 데이터를 넣으면 5쪽(`01 / 05`)이
나온다. 쪽 수와 쪽 번호 분모는 저장된 값이 아니라 데이터가 정한다.

## 집계는 호스트가 계산한다

`합계` 행과 백분율(`45.7%`)은 데이터 배열에 이미 들어 있어야 한다. 라이브러리는
받은 값을 찍기만 한다.

## 글꼴

호스트가 파일을 줘야 한다. `publish.mjs`의 `MalgunFontProvider`가 그 일의 전부다.
