# 학습형 구현 진행 상태

이 문서는 새 세션에서도 구현 및 학습 흐름을 이어가기 위한 기록이다.

- `미착수`: 아직 구현을 시작하지 않음
- `구현 중`: 일부 작업을 구현하고 있음
- `구현 완료`: 코드 작성과 해당 검증을 마침
- `학습 확인 중`: 구조 설명 이후 사용자 실습을 기다리고 있음
- `학습 확인 완료`: 사용자가 구조를 확인하고 작은 변경 실습까지 통과함
